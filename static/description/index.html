Stripe Connector

Pull Stripe invoices and credit notes into Odoo Accounting.

What you get

  • Daily cron syncs finalized Stripe invoices and issued credit notes into account.move.
  • Stripe customers and products are resolved — or created — on the fly.
  • Each move keeps the Stripe currency and the Stripe-rendered PDF as an attachment.
  • One Stripe Account per company, isolated by record rule.
  • Per-run history with pass / skip / fail counts and a chatter audit trail.
  • One-click Fetch Stripe Invoices button on the sales journal dashboard.

What you keep doing manually

  • Tax lines. Imported invoices land in draft. A human edits each move and adds tax so the Odoo total matches the Stripe total before posting.
  • Payment reconciliation. This module imports the invoice; matching it to a bank movement is left to your existing reconciliation workflow.

Auto-Confirm Invoices bypasses the manual review step and is intended for tax-free Stripe accounts only.

How the import stays correct

  • Deduplication. A SQL UNIQUE on stripe_invoice_id guarantees one Odoo move per Stripe object even under concurrent retries.
  • Late-finalized invoices. A configurable rolling Fetch Lookback (default 90 days) re-scans recent invoices on every cron tick, so subscription invoices created weeks before they finalize are never missed.
  • Watermark safety. The per-account “last successful fetch” only advances on a clean run — partial or failed runs are retried next cycle.
  • Crash recovery. A leftover running import-run from a worker that died mid-fetch is auto-failed at the start of the next fetch.

Security

  • Stripe Administrator (implied by Accounting Manager): manages Stripe Accounts, reads the API key, and is the only group that can write Stripe-ID fields on partners, products, and moves.
  • Stripe User (implied by Accounting User): read-only on Stripe Accounts and Import Runs.
  • The API key is field-level restricted — non-admins cannot read it back.
  • Record rules confine each Stripe Account and its runs to its company.

Requirements

Odoo 19.0 with the account module. Community is sufficient. A Stripe secret API key with read access to invoices, credit notes, customers, and PDFs.
